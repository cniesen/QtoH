Q to H
======
Redirects QRZ callsign lookups to HamQTH.

Any callsign lookups on the QRZ website ( i.e. https://www.qrz.com/db/A1BC ) will be redirected to the HamHQT 
page ( i.e. https://www.hamqth.com/A1BC ).  The use case for this add-on is when you are not using the QRZ 
website but instead HamQTH and want to ensure that 3rd party programs that open the QRZ page of an amateur 
radio callsign will instead open the corresponding HamQTH site.
